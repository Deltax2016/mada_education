# План разработки

Оценки — для **одного full-stack разработчика**. Для двоих (фронт + бэк) делить примерно на 1,7. Все сроки — календарные недели.

---

## Фаза −1 — Параллельные треки, стартующие немедленно

Это не разработка, но блокирует запуск. Начинать в первый день, потому что сроки не зависят от нас:

| Трек | Срок | Почему сейчас |
|---|---|---|
| **Онбординг Thawani** | недели | нужна CR, банковский счёт, комплаенс. Без UAT-ключей нельзя даже разрабатывать оплату |
| **Верификация домена в Resend** | дни | без неё письма уходят только на адрес владельца аккаунта, то есть войти сможет один человек |
| **Юридические документы** на ar/en | недели | оферта, политика конфиденциальности, возвраты — переводит человек |
| **Налоговая консультация** | — | облагаются ли онлайн-курсы НДС в Омане; ответ меняет ценообразование |
| **Проверка названия** | — | «mada» пересекается с саудовской платёжной схемой; переименование после запуска дорого |

Ни один из этих треков нельзя ускорить кодом. Все они всплывают в последнюю неделю перед запуском, если не начать сейчас.

## Фаза 1 — MVP · 6–8 недель

Цель: реальный студент проходит реальный курс на арабском. Доступ выдаётся вручную из админки — платежей ещё нет.

### 1.1 Identity · 0,5–1 нед
- Вход по email + код из шести цифр, письмо через Resend. Паролей нет
- Первый ввод кода создаёт аккаунт; отдельной регистрации нет
- Access/refresh с ротацией, HttpOnly-cookie через BFF, список сессий
- Роли, `require_course_role`, rate-limit на запрос кода
- Профиль: имя на ar и en, локаль, часовой пояс, аватар
- Запись согласий (`consents`) с версиями документов

### 1.2 Каталог и структура · 1–1,5 нед
- CRUD курсов, модулей, уроков в админке
- Локализуемые поля через JSONB, переключатель локали в редакторе
- Публичный каталог и карточка курса, ISR, `hreflang`, OG-картинки на двух языках
- Публикация/черновик, `available_locales`
- Поиск по каталогу с арабской нормализацией

### 1.3 Контент и редактор · 1,5–2 нед
- Блочный движок: реестр, zod + Pydantic-схемы
- Редактор на TipTap: heading, paragraph, list, quote, callout, image, code, divider, file, table, embed
- Рендерер блоков, RTL-корректный, с LTR-островками для кода и формул
- `lesson_versions` на локаль, draft/published, матрица готовности переводов
- Загрузка медиа presigned-аплоадом с прогрессом

### 1.4 Видео · 1 нед
- Плеер Vidstack: скорость, субтитры, главы, горячие клавиши, `dir="ltr"` на панели
- Heartbeat-прогресс, возобновление с позиции, антинакрутка перемоткой
- Постер и длительность через ffprobe в воркере
- **Без транскода** — прогрессивный MP4 с `faststart`
- Подписанные ссылки через `/playback` + watermark

### 1.5 Квизы v1 · 1–1,5 нед
- Типы: `single`, `multiple`, `boolean`, `short_text` (с арабской нормализацией), `number`
- Редактор квиза с двумя локалями
- Раннер: автосохранение, серверный дедлайн, восстановление после перезагрузки
- Грейдинг на сервере, `review_policy`, лимит попыток
- Клавиатурная доступность

### 1.6 Прогресс и доступ · 1 нед
- `enrollments`, ручная выдача из админки, импорт CSV
- **`AccessPolicy`** — все шесть исходов, покрыта тестами
- Отметка прохождения, агрегат по курсу, «продолжить с места остановки»
- Кабинет студента

### 1.7 Админка v1 · 0,5–1 нед
- Пользователи: поиск, блокировка, выдача/отзыв доступа
- По курсу: студенты, прогресс, результаты квизов
- Аудит-лог, impersonation с баннером

**Готово, когда:** сквозной e2e проходит зелёным в обоих направлениях — вход по коду из письма → выдача доступа → урок с видео и текстом → квиз → отметка о завершении, прогресс переживает смену устройства.

## Фаза 3 — Масштаб и качество · 4–5 недель

- **R2 + CDN:** переезд с MinIO, custom domain, приватные ссылки, Worker для проверки токена
- **HLS-транскод** (лестница с 360p) или переход на Cloudflare Stream; субтитры, автосубтитры Whisper с пометкой, транскрипт и поиск по видео
- **Потоки и drip:** когорты, расписание с учётом выходных, приглашения, дедлайны
- **Квизы v2:** `matching`, `ordering`, `fill_blank`, `essay` с ручной проверкой, банк вопросов с выборкой N, итоговый экзамен
- **Аналитика:** воронка курса, отвал по урокам, сложность вопросов, **сравнение ar и en** как индикатор качества перевода
- **Поиск:** Meilisearch, если Postgres FTS перестанет справляться на транскриптах
- **Геймификация:** очки, бейджи, стрики по локальной дате пользователя
- **PWA:** офлайн-оболочка, офлайн-очередь прогресса, скачивание материалов
- **Права субъекта данных:** экспорт, удаление с анонимизацией, задачи очистки по срокам
- **Производительность:** кэш каталога, ISR, устранение N+1, индексы под реальные запросы
- **Доступность:** полный проход по a11y на обеих локалях

## Фаза 4 — Расширение · по потребности

- **B2B:** организации, места, оплата по счёту, отчёты для менеджера, SSO
- **Мобильное приложение:** Expo поверх того же API
- **AI:** семантический поиск по материалам (pgvector), тьютор по курсу, черновики вопросов из транскрипта — с обязательной вычиткой человеком
- **Рассрочка** через Tabby/Tamara
- **Live-вебинары** через внешнего провайдера
- **Третья локаль** — проверка того, что архитектура локалей действительно не бинарная
- Реферальная программа, партнёрская программа

## Порядок, который соблюдается жёстко

1. **RTL и локали — с первого коммита.** Ретрофит стоит переписывания фронта.
2. **Деплой раньше фич.** Пока Coolify не отдаёт зелёный healthcheck — бизнес-логику не пишем.
3. **Деньги в minor units с самого начала.** Перешивание сумм задним числом — самый дорогой из возможных рефакторингов.
4. **`AccessPolicy` как единая точка** до появления платежей и потоков. Иначе логика доступа расползётся по десяти местам и там появятся дыры.
5. **Грейдинг на сервере с первого дня.** Перенос с клиента — переписывание модуля.
6. **`organization_id` в схеме сразу**, даже если не используется.
7. **Блочный редактор раньше «красивых уроков».** Это фундамент.
8. **Seed-данные и e2e «прошёл курс целиком» ×2 направления** — с первой недели.

## Риски

| Риск | Вероятность | Смягчение |
|---|---|---|
| **Онбординг Thawani затягивается** | высокая | начать в день ноль; PayTabs как резервный провайдер; ручная выдача доступа как временный режим продаж |
| **Письма с кодом уходят в спам** | средняя | верифицировать домен, настроить SPF, DKIM и DMARC до запуска; следить за bounce-рейтом в Resend |
| **Вход завязан на один канал** | средняя | без email войти нельзя вообще. Мониторинг доставки и алерт на всплеск `auth.email_send_failed` |
| **RTL-баги всплывают массово перед релизом** | высокая | Storybook ×2 направления и Playwright ×2 с первой недели, а не в конце |
| **Качество арабского перевода интерфейса и квизов** | средняя | человеческий перевод; метрика `locale_delta` по вопросам показывает плохие переводы объективно |
| **НДС на онлайн-курсы окажется применим** | средняя | цены с включённым налогом, ставка фиксируется в заказе; консультация до старта продаж |
| **Транскод кладёт VPS** | средняя | лимит CPU на воркер, ночная очередь, переход на Cloudflare Stream при росте |
| **Латентность из Европы раздражает** | средняя | Cloudflare с первого дня; переезд в ОАЭ остаётся выполнимым (всё в compose) |
| **Требование локального хранения данных от корпоративного клиента** | средняя | архитектура переносима; реестр субпроцессоров ведётся заранее |
| **Пиратство контента** | высокая | подписанные ссылки, watermark, лимит сессий; настоящий DRM — только managed |
| **Конфликт названия с саудовской mada** | неизвестна | проверка товарного знака до вложений в бренд |
| **Скоуп расползается** | высокая | Фаза 1 заморожена; всё новое — в бэклог Фазы 2 |
| **Потеря данных** | низкая, но фатальная | бэкапы Coolify → R2 + **ежемесячная проверка восстановления** |
